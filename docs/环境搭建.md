# WSL2 环境搭建指南

## 硬件配置

| 组件 | 规格 |
|------|------|
| GPU | RTX 5070 Ti 笔记本 12GB GDDR7 (140W) |
| CPU | 锐龙 R9 7945HX |
| RAM | 16GB |
| OS | Windows 11 + WSL2 Ubuntu 22.04 |

## 搭建步骤

### 1. 配置 WSL2 内存限制

在 `C:\Users\luo\.wslconfig` 创建：

```ini
[wsl2]
memory=12GB
```

```powershell
# PowerShell 中重启 WSL2
wsl --shutdown
```

### 2. 复制源码到 WSL2

```bash
# 在 WSL2 终端中
mkdir -p ~/agentopia
cp -r /mnt/d/Preson_database/AI-Vault/03_Projects_项目记录/Agentopia/源码/* ~/agentopia/
```

### 3. 安装 Python 环境

```bash
cd ~/agentopia
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pip install vllm huggingface_hub
```

### 4. 下载模型

```bash
huggingface-cli download Qwen/Qwen3-8B-AWQ \
  --local-dir ~/models/Qwen3-8B-AWQ
```

### 5. 配置 config.json

关键配置项：

```json
{
  "role_model": "qwen-8b",
  "god_model": "qwen-8b",
  "models": {
    "qwen-8b": {
      "url": "http://localhost:8000/v1",
      "vllm_model_name": "Qwen3-8B-AWQ",
      "api_key": "EMPTY",
      "context_length": 32768
    }
  },
  "world": {
    "time": { "n_year": 1, "n_week": 4 },
    ...
  }
}
```

### 6. 启动 vLLM 服务

```bash
python -m vllm.entrypoints.openai.api_server \
  --model ~/models/Qwen3-8B-AWQ \
  --quantization awq \
  --max-model-len 16384 \
  --gpu-memory-utilization 0.90 \
  --port 8000
```

### 7. 启动模拟

```bash
# 新终端
cd ~/agentopia && source venv/bin/activate
python scripts/run_world.py --max-agents 3 --years 1 --weeks 4 --parallel
```

## 散热方案

- 笔记本垫高 3-4cm 进风
- 空调房保持 25°C 以下
- GPU-Z 监控温度（核心 <80°C 安全）

## 断点续跑

```bash
# 从上次中断继续
python scripts/run_world.py --resume data/apartment_XXXXXX

# 从指定周继续
python scripts/run_world.py --resume data/apartment_XXXXXX --resume-from Y2020-W03
```

## Token 估算

- 3 agent × 10 weeks ≈ 500-800 万 token
- 在 5070 Ti 上约 18-28 小时
- 暑假可跑 300-400 小时
